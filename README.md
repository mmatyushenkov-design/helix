# Helix

Helix - трекер тренировок для атлетов средне-высокого уровня, облегчающий учёт периодизации и тренировочных циклов.

## О приложении

Helix — полностью локальное мобильное приложение (Flutter) для ведения тренировочного дневника, силовых циклов с периодизацией и анализа прогресса. Сеть не требуется ни для одной функции: данные хранятся на устройстве в SQLite.

- Силовые циклы 5/3/1 для базовых движений (присед, становая, жим лёжа, жим стоя) и волновая периодизация для остальных упражнений
- Дневник с календарём, плановыми подходами, RIR и AMRAP
- Статистика: расчётный максимум по Эпли, тоннаж, история подходов
- Резервное копирование и экспорт (ZIP с SHA-256, CSV)

## Структура проекта

- `frontend/` — Flutter-приложение (Android, iOS, Web, desktop)
- `backend/` — заготовки будущей серверной части (FastAPI), архитектура спроектирована с расчётом на её развитие
- `Техническая_документация_Workout_Tracker.docx` — полная техническая документация: архитектура, файловая система, алгоритмы, хранение данных и зависимости

## Сборка

```bash
cd frontend
flutter test --no-pub
flutter build apk --release --no-pub
```
